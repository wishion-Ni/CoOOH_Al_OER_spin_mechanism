# T01 publication package — OER staircase comparison

This is the manuscript-oriented delivery package for the selected OER comparison.

## Contents

- `source_data/staircase_source.csv` — long-format cumulative relative electronic energies.
- `source_data/staircase_source_wide.csv` — wide-format table convenient for Origin/Excel.
- `source_data/stepwise_dG.csv` — elementary-step energy changes.
- `plotting/plot_T01.py` — reproducible plotting script.
- `notes/figure_note.md` — scientific meaning, exact numbers, design decisions and usage.
- `notes/suggested_caption.md` — caption starting point.
- `figures/` — generated publication outputs (PDF/SVG/EPS/PNG/TIFF), produced by the rendering workflow.

## Canonical selected systems

- pristine CoOOH: Co32
- Al16 substituted system: neighboring Co7
- Al16 substituted system: Al47 control site

The source values mirror the corrected selected dataset in the parent T01 package. The parent directory retains provenance and candidate-comparison records; this publication package contains only the manuscript-facing representation.
