# C05 - Full-state cDFT constraint evolution

## Purpose
Extend the *O-focused C04 fingerprint into the complete *OH / *O / *OOH state sequence using already-computed cDFT constraint penalties.

## Figure
Two panels show N-1 and N+1 constraints. Each panel compares:
- pristine vs Al-substituted CoOOH
- Co-only vs Co+adsorbate localization scope
- *OH, *O and *OOH states

The figure deliberately omits the *O Co-only-spin M+2/M-2 branches because those are already handled by C04. The full source table retains them for provenance.

## Main robust observation
Across the reaction-state sequence, Co+adsorbate localization penalties remain substantially lower than Co-only penalties. This supports an electronically distributed Co-O response rather than purely Co-localized charge accommodation.

## Critical limitation
These values are cDFT constraint penalties. They are **not** CHE free energies, reaction barriers, electrode potentials, or kinetic activation energies.
