# Theory Figure Delivery Package

This directory is the manuscript-facing index for theoretical figure components supplied to collaborators. It does not prescribe final manuscript figure numbering or multi-panel arrangement. Each computational figure is prepared as an independent subfigure so the manuscript team can combine, relabel, or redraw it as needed.

A figure is `figure_ready` only when it has source numerical data in a software-neutral format, a reproducible plotting/rendering procedure, vector output for conventional plots, high-resolution raster output where appropriate, a scientific note with limitations, and a suggested caption.
