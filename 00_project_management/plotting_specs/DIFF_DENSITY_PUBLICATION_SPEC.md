# DIFF_DENSITY_PUBLICATION_SPEC

## Purpose
Specification for manuscript-quality difference density figures.

## General requirements

Figures are prepared as independent subfigures for journal assembly.

Required outputs:
- PNG 600 dpi
- TIFF 600 dpi
- PDF
- SVG/EPS when possible
- source data
- plotting script

## Charge density difference

Use:

Δρ = ρ(*O)-ρ(*OH)

Requirements:
- zero-centered diverging color scale
- identical scale between pristine and Al systems
- show atomic positions
- highlight active Co-O region

## Magnetization and spin maps

Prepare:
- magnetization difference
- spin-up difference
- spin-down difference

Use identical visualization limits between comparable systems.

## Atomic overlay

Use consistent labels:

Co: gray
Al: orange
O: red
H: white

Show only chemically relevant atoms.

## Layout

Optimize for multi-panel journal figures:
- readable font size after scaling
- complete borders
- clear color bars
- consistent orientation
- no excessive annotation

## Scientific focus

The figure should emphasize:

- Co-centered reconstruction in pristine CoOOH
- altered charge/spin redistribution pathway after Al substitution
- relation to cDFT, PDOS and OER mechanism.
