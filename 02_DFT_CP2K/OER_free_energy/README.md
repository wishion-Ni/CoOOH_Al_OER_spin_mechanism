# OER free-energy calculations

This directory stores OER thermodynamic calculations and selected free-energy staircases.

## Important dataset note

Some calculations in the project contain different optimization stages, computational settings, and site selections. Therefore, not every generated staircase should be treated as a final result.

The currently identified useful dataset from the preliminary staircase comparison is:

- undoped CoOOH: black curve
- Al-substituted CoOOH active Co site adjacent to Al: green curve
- Al-related site: red curve (used mainly as evidence that Al itself is not the active catalytic center)

When future Codex sessions archive calculation outputs, these curves should be searched and stored separately from other trial calculations.

## Scientific purpose

The selected dataset is used to establish:

1. pristine CoOOH OER energetics;
2. activity enhancement after Al substitution at neighboring Co sites;
3. exclusion of Al as the direct active site.

The free-energy data should later be combined with cDFT, charge analysis, and bonding analysis to construct the mechanism of the *OH -> *O step.
