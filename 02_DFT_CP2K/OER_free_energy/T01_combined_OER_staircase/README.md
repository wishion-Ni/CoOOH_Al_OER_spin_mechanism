# T01 Combined OER Free-Energy Staircase

Publication figure source package for `T01_combined_OER_staircase_comparison`.

## Selected systems

| Label | Meaning | Source branch |
|---|---|---|
| `CoOOH_pristine` | pristine CoOOH, active Co32 | `undoped_001333/oer/sites/site01_surface_Co32` |
| `Al16_Co7_adjAl` | Al-substituted CoOOH, active Co7 adjacent to Al | `Al16/oer/sites/site03_bulk_Co7_adjAl` |
| `Al16_Al47_control` | Al-related Al47 site used as the Al-site control | `Al16/oer/sites/site02_surface_Al47` |

The main table is the final historical CP2K three-site comparison used in the archived supporting figure. It uses conventional four-step AEM/CHE bookkeeping; the O2 endpoint is nominally closed to 4.920000 eV. These are historical electronic-energy values without vibrational correction, not the later strict 298.15 K CHE series.

## Contents

- `source_data/staircase_source.csv`: long-format source table.
- `source_data/staircase_source.xlsx`: the same table in spreadsheet form.
- `source_data/data_note.md`: units, sign convention, closure and validation notes.
- `calculation_origin/source_location.md`: source paths and selection rationale.
- `candidate_comparison.md`: historical candidate records that were not mixed into the main dataset.
- `plotting/plot_template.py`: reproducible Matplotlib script for the staircase figure.
- `T01_combined_OER_staircase_comparison.png`: generated preview using the template.

## Reproduce

From this directory:

```text
python plotting/plot_template.py --input source_data/staircase_source.csv --output T01_combined_OER_staircase_comparison.png
```

The plot shows cumulative electronic OER energy relative to `*`. It is a historical comparison, not a claim that all three records were generated by a new calculation run or that these values are the final strict CHE potentials.

## Scope and limitations

Only processed numerical tables, metadata and figure-preparation files are included. OUTCAR, WAVECAR, restart files, trajectories and large cube files are excluded. Historical candidate branches remain documented but are not silently averaged or merged. The selected records are suitable for a comparison figure package; final manuscript claims still require the calculation-origin records and method limitations to be cited.
