# Validated VASP Analysis List

## Purpose

Record the status and intended use of VASP-based electronic-structure analyses.

This file prevents exploratory calculations from being directly used as manuscript evidence without validation.

---

# COHP / LOBSTER

Status:

candidate or supporting dataset depending on pair validation.

Requirements for manuscript use:

- correct structure association
- validated Co-O pair selection
- acceptable projection quality
- avoid ambiguous orbital assignment

Purpose:

Explain bonding changes during OER intermediate conversion.

---

# Bader charge

Status:

supporting dataset

Purpose:

Provide charge-partitioning information.

Limitation:

Small net charge differences do not exclude substantial orbital or spin redistribution.

Interpret together with cDFT and density analysis.

---

# PDOS / d-band analysis

Status:

candidate/supporting dataset.

Purpose:

Identify changes in electronic states and orbital contributions.

Requirement:

Use state fingerprinting rather than raw band-index assignment when comparing different structures.

---

# Charge density difference

Status:

candidate/supporting dataset.

Purpose:

Visualize spatial electronic redistribution.

Limitation:

Do not interpret directly as formal oxidation state.

---

# Spin density analysis

Status:

candidate/supporting dataset.

Purpose:

Support the spin-reorganization mechanism.

Requirement:

Maintain consistency with method-dependent spin definitions.
