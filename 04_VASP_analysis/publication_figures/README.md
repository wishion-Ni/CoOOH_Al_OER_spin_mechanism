# Publication figure components

This directory contains standalone manuscript-ready figure components generated from validated publication data interfaces.

## Scope

The goal is not to generate final manuscript composite figures. Each output should remain an independent scientific panel that can be assembled by manuscript authors.

## Modules

- V01_COHP: bonding interaction analysis
- V02_diff_density: charge redistribution and local integration
- V03_spin_density: spin-density evolution
- V04_PDOS: orbital-resolved electronic structure

## Requirements

All plots should:

- use validated data under `publication_figure_data`
- retain data provenance
- export vector formats when possible
- avoid infographic-style annotations
- keep interpretation in captions rather than inside panels
